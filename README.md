# Crafvy Releases

Official download artifacts and CI runner for [Crafvy](https://crafvy.com).

## Downloads

Latest desktop app for macOS, Windows and Linux → **[Releases](../../releases/latest)**.

For a friendly download picker with auto-detection of your OS, see
[crafvy.com/download](https://crafvy.com/download).

## What's in this repo

This repo receives release artifacts (`.dmg`, `.msi`, `.AppImage`, …)
produced by the CI workflows in `.github/workflows/`. The Crafvy
source lives elsewhere.

## Reporting issues

Bugs, feature requests, and support belong at
[crafvy.com/support](https://crafvy.com/support), not here.
